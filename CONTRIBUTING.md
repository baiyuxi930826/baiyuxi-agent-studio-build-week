# Contributing

Issues and pull requests are welcome for the Build Week edition.

Before submitting a change:

1. Keep credentials and private runtime data out of commits.
2. Run `pnpm build`, `pnpm check`, and the relevant tests.
3. Explain the user impact and verification evidence in the pull request.
4. Do not add Clowder AI cat assets, unlicensed third-party media, or private screenshots.

By contributing, you agree that your contribution may be distributed under the repository's MIT License.
