# Security Policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/baiyuxi930826/baiyuxi-agent-studio-build-week/security/advisories/new).

Do not include credentials, tokens, private prompts, personal information, or production configuration in a public issue.

## Public repository boundary

This repository contains no production `.env`, browser profile, deployment bundle, private transcript, or runtime database. Local secret files and deployment artifacts are ignored by Git.

## Supported version

Security fixes target the current `main` branch during OpenAI Build Week 2026.
